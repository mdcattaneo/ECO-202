## Purpose

This folder will contain notes prepared by the ECO 202 teaching assistants for the course's weekly precepts. The notes will connect the relevant class guides to selected examples, calculations, interpretations, coding demonstrations, and ungraded practice without creating a second course sequence.

## How to use the notes

When a weekly note is released:

1. identify the class guides and practice modules it supports;
2. attempt any designated questions before reading worked discussion;
3. use the note to compare methods, repair misconceptions, and prepare questions for the teaching assistants; and
4. return to the class guide for the common-core statement, notation, assumptions, and limitations.

Precept notes supplement the instructor-led classes. The syllabus, instructor announcements, class guides, and explicit corrections remain authoritative when materials differ.

## Release and privacy

Notes will appear here as they are prepared and approved. No student names, work, grades, accommodations, attendance records, or other private information belongs in this public folder.
