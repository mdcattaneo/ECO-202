# Class 5 data

[← Class guide](../) · [Course data library](../../../assets/data/wooldridge/)

`bwght.csv` is a local, software-neutral copy of the `bwght` dataset distributed with version 1.4-7 of the `wooldridge` R package. It contains 1,388 births and 14 variables from a 1988 National Health Interview Survey extract. Class 5 compares birth weight and family income across records with zero and positive reported cigarette consumption.

The file is historical and observational. These group differences are descriptive associations, not causal estimates. Complete variable definitions and original-source notes are available in the [`wooldridge` package manual](https://CRAN.R-project.org/web/packages/wooldridge/wooldridge.pdf).
