These guides form the student-facing learning spine for Fall 2026. Each numbered class folder contains its guide, reproducible files, and a nested ungraded `practice/` module with worked solutions, so the complete instructional unit can be downloaded and used together. Dates and administrative policies remain governed by the [course syllabus](../ECO202-Fall2026-Syllabus.pdf) and official announcements.

## Class-folder workflow

1. Prepare and navigate with the class `README.md`.
2. Run adjacent code, data, or figures when the guide directs you to them.
3. Complete the nested ungraded `practice/` route after class.
4. Open `practice/solutions/` only after a genuine attempt, then close it and reconstruct the reasoning.
5. Retain the common core by completing the nearby transfer without assistance.

## Recurring learning structure

Across the semester, the guides repeatedly connect:

> Economic question → data and design → statistical object → computation → uncertainty → interpretation and limitations

Each class separates the **common core** expected independently on closed-book exams from optional **Explore further** paths. Selected AI interactions model how to specify, question, verify, and revise generated work; they do not make AI output authoritative.
