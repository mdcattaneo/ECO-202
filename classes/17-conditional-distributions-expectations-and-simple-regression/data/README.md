# Class 17 data: `wage1`

[← Class guide](../) · [Course data library](../../../assets/data/wooldridge/)

`wage1.csv` is a class-local, software-neutral copy of the `wage1` dataset distributed with version 1.4-7 of the `wooldridge` R package. It contains 526 worker records and 24 variables from a 1976 Current Population Survey extract. Class 17 uses hourly wage in 1976 dollars and years of education to illustrate empirical conditional means, a simple fitted regression line, and heteroskedasticity-robust slope inference.

The data are historical and observational. The wage–education line is not automatically causal, does not describe the current labor market, and does not identify an individual worker's return to another year of schooling. Selection, measurement, functional form, omitted variables, dependence, and external validity remain substantive issues.

Complete variable definitions and original-source notes are available in the [`wooldridge` package manual](https://CRAN.R-project.org/web/packages/wooldridge/wooldridge.pdf). The course-level canonical copy is [`../../../assets/data/wooldridge/wage1.csv`](../../../assets/data/wooldridge/wage1.csv).
