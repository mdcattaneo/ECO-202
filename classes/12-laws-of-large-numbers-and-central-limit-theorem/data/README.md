# Class 12 data

[← Class guide](../) · [Course data library](../../../assets/data/wooldridge/)

`wage1.csv` is a local, software-neutral copy of the `wage1` dataset distributed with version 1.4-7 of the `wooldridge` R package. It contains 526 worker records and 24 variables from a 1976 Current Population Survey extract. Class 12 treats the 526 recorded wage values as a fixed teaching population and samples rows independently with replacement to illustrate the law of large numbers, the central limit theorem, and Normal approximations for means and counts.

This row-sampling experiment is a teaching probability model. It does not claim that the file is the target population for a substantive labor-market question or reconstruct the original CPS sampling process. Complete variable definitions and original-source notes are available in the [`wooldridge` package manual](https://CRAN.R-project.org/web/packages/wooldridge/wooldridge.pdf).

The data are historical and observational. They do not describe the current U.S. labor market, and associations in the file are not automatically causal.
