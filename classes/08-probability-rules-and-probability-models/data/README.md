# Class 8 data

[← Class guide](../) · [Course data library](../../../assets/data/wooldridge/)

`wage1.csv` is a local, software-neutral copy of the `wage1` dataset distributed with version 1.4-7 of the `wooldridge` R package. It contains 526 workers and 24 variables from a 1976 Current Population Survey extract. Class 8 uses the education and hourly-wage variables to define events in a finite teaching probability model.

The records are historical and observational. Uniformly selecting one of the 526 rows is a course-created random mechanism for learning probability; it is not the original CPS sampling design and does not make these rows representative of current workers. The event calculations are descriptive and do not identify a causal effect of education on wages. Complete variable definitions and original-source notes are available in the [`wooldridge` package manual](https://CRAN.R-project.org/web/packages/wooldridge/wooldridge.pdf).
