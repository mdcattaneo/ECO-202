# Class 4 data

[← Class guide](../) · [Course data library](../../../assets/data/wooldridge/)

`wage1.csv` is a local, software-neutral copy of the `wage1` dataset distributed with version 1.4-7 of the `wooldridge` R package. It contains 526 workers and 24 variables from a 1976 Current Population Survey extract. Class 4 uses hourly wage and completed education to study scatterplots, correlation, fitted lines, residuals, and descriptive regression.

The file is historical and observational. It does not describe current wages, and the education–wage association does not by itself identify a causal effect. Complete variable definitions and original-source notes are available in the [`wooldridge` package manual](https://CRAN.R-project.org/web/packages/wooldridge/wooldridge.pdf).
