## Coverage

Random variables, expectation, variance and covariance, sampling distributions, laws of large numbers, the central limit theorem, and point-estimator properties. Earlier course knowledge remains a prerequisite; there is no separate cumulative section.

Read discrete distributions and CDFs; compute expectations, variances and covariances; construct small exact sampling distributions; distinguish counts, proportions and means; apply LLN/CLT with assumptions; separate bias, variance, MSE and estimated standard errors.

Hypothesis tests, confidence intervals, and conditional expectations begin in the next module. Longer joint-distribution algebra and other labeled optional extensions are not targets. Follow the common-core boundaries in the current class guides and any explicit instructor clarification.

## Preparation and format

Start with the module’s guides and class-local practice, then use the [two full practice exams](practice/) for timed unaided attempts. Each paper contains four multiple-choice questions and four written problems, totaling 100 points and targeting 70 minutes. Consult the [common conditions and practice sequence](../README.md#common-format-and-conditions).
