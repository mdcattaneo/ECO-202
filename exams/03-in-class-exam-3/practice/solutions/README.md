**Status:** Released September 6, 2026

Open a solution after a genuine attempt, or make an explicit choice to study an example instead of simulating an exam. The solutions explain why the correct multiple-choice option works and why the alternatives do not, and show the reasoning for each written part.

- Practice Exam 3 — Version A: [worked solutions PDF](ECO202-Fall2026-Exam3-PracticeA-Solutions.pdf) · [LaTeX source](ECO202-Fall2026-Exam3-PracticeA-Solutions.tex)
- Practice Exam 3 — Version B: [worked solutions PDF](ECO202-Fall2026-Exam3-PracticeB-Solutions.pdf) · [LaTeX source](ECO202-Fall2026-Exam3-PracticeB-Solutions.tex)

Equivalent exact expressions and valid alternative arguments are acceptable. Compare assumptions and interpretations as carefully as arithmetic. After studying a missed problem, close the solution and reconstruct it without help; then return to the class guide or practice for a related task. A remembered answer is not evidence that you can solve a new problem.

To compile, keep this `solutions/` folder inside the complete practice folder: its sources use `../exam-style.tex`. Follow the [build-and-clean instructions](../../../README.md#latex-sources-and-compilation); the script compiles in place and leaves only each solution's `.tex` and PDF alongside this README. Opening a solution's source reveals the answers just as opening its PDF does.

These are practice solutions only. No unreleased real-exam solutions are included.
