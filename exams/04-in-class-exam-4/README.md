## Coverage

Hypothesis tests, p-values, errors and power, confidence intervals, inference for means and proportions, conditional expectation and iterated expectations, simple regression, slope inference, and causal limitations. Earlier course knowledge remains a prerequisite; there is no separate cumulative section.

State a null and alternative; construct and interpret tests and confidence intervals; select the correct sampling unit and standard error; distinguish paired and independent comparisons; calculate conditional averages; interpret simple-regression estimates, uncertainty and causal limits.

Technical multiple-regression calculations, derivations of robust standard errors, and project-specific deliverables are not exam targets. Class 18 contributes conceptual control and causal-interpretation ideas. Follow the common-core boundaries in the current class guides and any explicit instructor clarification.

## Preparation and format

Start with the module’s guides and class-local practice, then use the [two full practice exams](practice/) for timed unaided attempts. Each paper contains four multiple-choice questions and four written problems, totaling 100 points and targeting 70 minutes. Consult the [common conditions and practice sequence](../README.md#common-format-and-conditions).
