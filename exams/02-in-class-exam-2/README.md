## Coverage

Populations and samples, survey and selection bias, randomized experiments, probability rules, conditional probability, independence, and Bayes’ rule. Earlier course knowledge remains a prerequisite; there is no separate cumulative section.

Define the population and sampling frame; distinguish random sampling from random assignment; enumerate small sample spaces; use event algebra, conditioning, independence and base rates; interpret causal comparisons under their design assumptions.

Expectation notation, sampling-distribution theory, confidence intervals, and hypothesis tests are not targets of this module. Follow the common-core boundaries in the current class guides and any explicit instructor clarification.

## Preparation and format

Start with the module’s guides and class-local practice, then use the [two full practice exams](practice/) for timed unaided attempts. Each paper contains four multiple-choice questions and four written problems, totaling 100 points and targeting 70 minutes. Consult the [common conditions and practice sequence](../README.md#common-format-and-conditions).
